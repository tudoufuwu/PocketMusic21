# 21键手机播放器（Android MVP）

对外名称：21键弹琴自动化（Android 双端曲库）。原生 Kotlin + Jetpack Compose 的横屏 21 键自动演奏器，直接兼容 Windows 版 TXT 曲谱语义。

## 当前能力

- 内置 240 首曲谱；主界面和游戏内悬浮窗均可搜索选歌，列表可滚动显示完整曲库。
- 悬浮窗支持“点歌即播”、播完停止/顺序播放/单曲循环、最近播放、收藏、每曲独立速度、推荐速度、进度、暂停/继续/停止与可拖动音乐球。
- 游戏内透明 3×7 校准层：整体移动、横纵缩放网格、单点精修、三行同步上下移动、七列同步左右移动、保存/取消；坐标归一化，适配不同屏幕比例。
- TXT 行格式：`按键 拍数`；`p` 为休止，连续多个键为同时和弦。
- 主播放器不包含游戏内录制或透明触摸捕获层；收缩音乐球旁直接显示当前选曲、“播放”和“停止”，播放只作用于当前选中的歌曲，停止不会清除选曲。
- 独立 `scoreMaker` 制谱器模块（包名 `com.shadowtrace.scoremaker21`）提供自有横屏 21 键制谱：开始、暂停/继续、停止、撤销、删除、清空、近同时按键和弦、0.5 拍量化、`p` 休止，以及通用 TXT 导入/保存。它不需要无障碍或悬浮窗权限，可与主播放器同时安装。
- 不需要 Root、Shizuku、登录或网络；不申请普通悬浮窗权限。
- 锁屏、无障碍服务真正关闭或用户主动停止后不继续派发新手势；音量、充电、旋转、通知等瞬时系统界面不会主动终止播放。主播放器当前版本仍需真机确认 OEM 行为。
- AI 制谱同步、制谱器 TXT 导入和跨端交接规范见 [`docs/AI_SONG_WORKFLOW.md`](docs/AI_SONG_WORKFLOW.md)。

## 使用顺序

1. 启用系统无障碍设置中的“21键悬浮演奏”。
2. 点“打开悬浮曲库”，切回游戏弹琴界面。
3. 悬浮面板点“校准”，把 3×7 网格移到琴键区域，先“缩放网格”，再“单点修正”，最后保存。
4. 在悬浮窗搜索歌曲；“点歌即播”开启时，点歌曲即播放并自动收成音乐球。
5. 可切换播放模式、收藏、推荐/自定义速度；紧急时展开音乐球点“停止”。
6. 紧急时点收缩态旁的“停止”。需要制作新谱时单独打开制谱器，在其自有 21 键内开始记录，停止后用“保存 TXT”导出，再在播放器主界面导入/测试。
